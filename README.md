# Ad-Spot

Ad-Spot is a responsive front-end advertisement website developed using **HTML, CSS, and JavaScript**. It allows users to browse advertisements, search for products and services, submit enquiries or reports, and provides an administrator dashboard for managing submitted reports.

---
## Project Description

Ad-Spot is designed to connect buyers and sellers through a simple and user-friendly interface. Users can browse advertisements from different categories, search for products, and contact the website administrators using the contact form.

The project demonstrates responsive web design, client-side form validation and dynamic content manipulation using JavaScript.

## How to Run

1. Download or clone the project.

```
git clone git@github.com:Drizzy676/ad-spot.git 
```

2. Open the project folder.

3. Open **index.html** in your web browser.

No installation or server is required.
